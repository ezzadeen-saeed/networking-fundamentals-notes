# Linux Basics for Beginners

## Objective
Learn basic Linux commands commonly used when working with systems and networks.

## Commands

### pwd
Displays the current working directory.

### ls
Lists files and directories in the current directory.

### cd
Changes the current directory. Example: `cd Documents`.

### mkdir
Creates a directory. Example: `mkdir practice`.

### man
Displays a command's manual when the manual is installed. Example: `man ls`.

## Practice Plan
