# Network Configuration Lab

## Objective
Understand the basic network settings used by a connected device.

## Concepts
- **IP address:** Identifies a network interface at the IP layer.
- **Subnet mask/prefix:** Defines the IP network prefix.
- **Default gateway:** Provides a next hop for traffic leaving the local subnet.
- **DNS server:** Resolves domain names into DNS records.
- **DHCP:** Can automatically assign IP configuration to a device.

## Lab Environment
- Device: Android phone
- Connection type: Wi-Fi
- Network details: Not recorded in this template

## Procedure
1. Open the phone's Wi-Fi settings.
2. Select the connected network and view its details.
3. Identify which IP configuration fields are displayed.
4. Record only non-sensitive observations.

## Results
To be completed after checking the device settings.

## Analysis
Explain what each observed setting means. Do not assume that a field was observed if it was not displayed.

## Learning Outcome
This lab is intended to build familiarity with IP configuration and local network troubleshooting.
