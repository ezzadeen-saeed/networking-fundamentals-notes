## Topics Covered

### 1. Computer Networks
A computer network is a group of connected devices that communicate and share information and resources.

### 2. IP Address vs MAC Address
- **IP address:** A logical address used to identify a device's network interface and support communication across networks.
- **MAC address:** A link-layer address used to identify a network interface on a local network, subject to how the interface is configured.

### 3. DNS
The Domain Name System (DNS) translates domain names, such as example.com, into information used to locate internet services, commonly IP addresses.

### 4. DHCP
Dynamic Host Configuration Protocol (DHCP) automatically provides network configuration, such as an IP address, subnet mask, default gateway, and DNS servers.

### 5. TCP vs UDP
- **TCP:** Provides a reliable, ordered byte stream between applications.
- **UDP:** Sends datagrams without TCP's delivery or ordering guarantees.
